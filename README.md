NASA Space Helper
- Project Idea
NASA Space is a simple tool designed to help NASA organize space mission tasks and information.
It can be used to track important mission tasks and provide useful space-related information.

-Technologies
- HTML
- CSS
- JavaScript
- GitHub

-How to Run:
1. Download or clone the repository.
2. Open the project folder.
3. Open the HTML file in a web browser.
4. Use the tool to view and manage space mission information.

-Purpose:
The aim and goal of this project is to show how GitHub and project management can be used to plan and develop a simple application for NASA.
