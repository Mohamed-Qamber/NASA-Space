Reflection

What I Learned
I gained knowledge about software development project management with the help of GitHub. Learned to make repositories, issues, branches, commits and pull requests. I also gained some knowledge on how project preparation can help organise the work prior to the development of the project.

What Was Challenging
The most difficult aspect of working with open source is understanding the concepts and terminology for branches and pull requests. I did multiple commits and then merged the branch to see how it works.

What Was Fun
Making the NASA project idea was fun... and watching how the various features of GitHub could be applied to it.

If I could improve this, I would...
More time would be spent in making the user interface more user-friendly, as well as the capabilities to edit/manage tasks and add more NASA mission information.
